Nightkeeper

A self-hosted implementation of Laravel Nightwatch's cloud dashboard — keep the official agent, own your telemetry.

View on GitHub ↗

What it is

Nightwatch's local agent (php artisan nightwatch:agent) streams request, query, exception, job, and command telemetry from a Laravel app to a hosted dashboard over a small HTTP contract — nothing about that contract is tied to Laravel's own servers. Nightkeeper re-implements just that hosted half: it authenticates the agent, accepts its ingest batches, and renders the same categories of data the monitored app already produces. No telemetry leaves infrastructure you control, and there's no recurring bill for the privilege of seeing your own exceptions.

What it does

  • Multi-tenant by design Organizations → Applications → Environments, each with its own rotatable ingest token.
  • Full event coverage Requests, queries, exceptions, commands, scheduled tasks, jobs, outgoing requests, cache, mail, and notifications — grouped and aggregated.
  • Request waterfalls Every trace reconstructed span-by-span, from bootstrap through termination.
  • Sentry-style issue tracking Unhandled exceptions grouped by class/file/line — occurrence counts, affected users, real stack traces, open/close workflow.
  • Signed ingest auth Short-lived HMAC-signed JWTs issued per environment, rotatable on demand.

How it works

  1. The agent authenticates: POST /api/agent-auth with an environment's ingest token returns a short-lived signed JWT.
  2. It streams telemetry: gzip'd JSON batches of records are POSTed to /api/ingest.
  3. Nightkeeper indexes and shows it: events are grouped, aggregated, and rendered across the same dashboards a hosted product would give you.
